# Aljazira Takaful (AJT) — medical cover, network held by TCS

## Status

**Products known. Network served by TCS, not published.** Aljazira Takaful sells **Medical** to
individuals, corporates and domestic helpers, and publishes no provider list. Its own site directs
all medical-network questions to **TCS**, the third-party administrator that also serves Al Sagr
and Buruj members in this project.

**No hospital may be named from this skill.**

Verified 11 November 2026. See `sources/index.md`.

---

## First: the domain in the request is dead

`ajt.com.sa` — the URL supplied — **does not respond**. DNS resolves (37.99.173.14) but every
connection times out. The last Wayback capture is from March 2022.

The company's live site is **`www.aljaziratakaful.com.sa`**. `ajt.com.sa` survives only as the
**email domain** (`info@ajt.com.sa`). See `sources/index.md`.

## The rule this skill exists to protect

A hospital may accept Aljazira Takaful and still not accept the member's class. This skill works
at class level and names no providers, because none are published.

## The finding: TCS is the medical front door, stated openly

Aljazira Takaful's own footer and download-centre page state:

> **"Medical Services available 24/7"**
> "To access medical services, please call the unified number **8003040400 and select extension
> (2)**, or download the medical insurance app."

And the app it links to is **"Total Care Saudi"**, with the Android package id
**`com.chatilaah.tc`** — a TCS app. The site's media folder even contains
`Content/media/TCS_Footer.jpg`.

So: the insurer names its administrator, gives the exact extension, hands over the
administrator's app, and carries the administrator's branding in its own footer. **That is the
most complete TCS disclosure of any company in this project.**

## What the agent must do for an Aljazira Takaful user

1. Confirm the company is **Aljazira Takaful** (الجزيرة تكافل), sometimes abbreviated **AJT**.
   If they hold **Aljazira** health, confirm it is not another Aljazira entity.
2. Ask the class on their card (Class A / Class B). If they do not know, say where to look and wait.
3. Ask the city and the service.
4. **Do not name a hospital.** Say plainly that Aljazira Takaful does not publish a provider list.
5. Give them the route the insurer itself publishes:
   - **Call 8003040400 and select extension 2** — medical services, **24/7**. Ask whether a named
     hospital is in the network for their class.
   - **Or use the Total Care Saudi app** — shows the member's own network.
   - International callers: +966 12 6688877.
6. Give the hospital question: *"Do you bill Aljazira Takaful Class [A/B] directly?"*
7. State that coverage and networks change, so confirm before travelling.

### The answer block — use this shape every time

1. **What they hold:** Aljazira Takaful medical policy — individual, corporate or domestic helper.
2. **Class:** ask for Class A / Class B; Aljazira publishes no tier names.
3. **What to do next:** call **8003040400 and select extension 2** (medical services, 24/7), or use
   the **Total Care Saudi** app.
4. **Always ask the hospital:** *"Do you bill Aljazira Takaful Class [A/B] directly?"*
