### How to read this honestly

Two readings are possible and this skill cannot choose between them:

1. GGCI re-accredited most providers but has not republished the file — the network is intact
   and only the document is stale.
2. The SME network genuinely shrank and most providers left it.

**Do not assert either.** Tell the user the file is from September 2025, that almost every
accreditation in it has lapsed, and that GGCI must confirm current coverage.
