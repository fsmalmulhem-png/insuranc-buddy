# Ggi Gulf General — provider data at a glance

## How many providers

**423 providers** across **59 cities** — but only **2** still hold valid accreditation.

## Where the network data lives

The SME network PDF on `ggi-sa.com`, 13 pages, dated 14 September 2025.

## Why it is in (or not in) this skill

It **is** in this skill: see the 59 files under `network/`. Every row carries its expiry date and a validity flag.

## Can this skill name a hospital?

**Partially.** A provider may be named only as a September-2025 listing, with its expiry stated. Only two rows are still valid — see `tiers-and-packages.md`.

This file exists so every skill in the set has the same shape. Four skills hold full hospital
tables under `network/`; the other twenty-one cannot, because the underlying data was never
