# Amana Coop — provider data at a glance

## How many providers

**1,851 unique providers** across **159 cities**.

## Where the network data lives

Two published network PDFs on `amana.sa`, dated 21 May 2026 (49 pages and 43 pages).

## Why it is in (or not in) this skill

It **is** in this skill: see the 159 files under `network/`, one per city.

## Can this skill name a hospital?

**Yes** — with one limit: the sub-tier (Advance/Elite/Standard) could not be recovered from the tick marks, so the skill names the provider and the list it came from, not the sub-tier.

---

This file exists so every skill in the set has the same shape. Four skills hold full hospital
tables under `network/`; the other twenty-one cannot, because the underlying data was never
published, is member-locked, or is out of date. Absence there is a finding, not a gap in the work.
