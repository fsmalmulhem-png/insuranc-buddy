# Gig Gulf Insurance — provider data at a glance

## How many providers

**3,437 named providers** across **357 cities** — each tagged with its network tier.

## Where the network data lives

`gig.sa/provider-locator` — the entire dataset is embedded in the page HTML, which is why it could be extracted in full.

## Why it is in (or not in) this skill

It **is** in this skill: see the 355 files under `network/`, one per city.

## Can this skill name a hospital?

**Yes.** Name the provider, state its network tag (VVIP/VIP/A+/A/B+/B/C/D/E), type, address and telephone.

---

This file exists so every skill in the set has the same shape. Four skills hold full hospital
tables under `network/`; the other twenty-one cannot, because the underlying data was never
published, is member-locked, or is out of date. Absence there is a finding, not a gap in the work.
